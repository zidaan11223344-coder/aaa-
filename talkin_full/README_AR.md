# بوت Talkin الكامل على جينات شات (Giant Chat)

هذا المجلد يجعل مستودع **aaa** نسخة كاملة من بوت **Talkin** تعمل على تطبيق **جينات شات** بدل شبكة Talkin الأصلية. بوت السفير القديم (`bot.py`) بقي كما هو ولم يُحذف؛ يمكن تشغيل أي منهما من نفس المستودع.

## الفكرة

بوت Talkin الأصلي مبني على `websocket` وحزم `protobuf` خاصة به. كل أوامره وميزاته موجودة داخل `bot.py` الأصلي (حوالي 32 ألف سطر و440 دالة). لذلك لم نُعد كتابة الألعاب أو الخدمات، بل نقلنا البوت كما هو داخل `talkin_full/vendor/talkin_bot.py` واستبدلنا **طبقة النقل فقط**:

| الطبقة | Talkin الأصلي | هذه النسخة |
|---|---|---|
| الاتصال | WebSocket + protobuf | Supabase (نفس ما يستخدمه تطبيق جينات شات) |
| رسائل الغرف | `room_message` packets | جدول `room_messages` |
| الرسائل الخاصة | `chat_message` packets | جدول `dm_relay` |
| الانضمام والخروج | `room_join` / `room_leave` | دوال `room_join` / `room_leave` / `room_heartbeat` |
| الإدارة | `room_admin` packets | `kick_room_member` / `ban_room_member` / `set_member_rank` |
| الوسائط | خادم ملفات Talkin | رفع إلى Supabase Storage ثم إرسال الرابط |
| الأوامر والألعاب | `TalkinBot` | نفس الكلاس دون تعديل، عبر الوراثة |

الملفات الأساسية:

- `vendor/talkin_bot.py` — نسخة حرفية من بوت Talkin (الأوامر، الألعاب، النقاط، الهدايا، الاستكشاف، النشر، الموسيقى، الكريكيت، المزاد، لودو، الثعبان، المزرعة، المحفظة، البنك...).
- `adapter.py` — كلاس `GiantTalkinBot` الذي يترجم الحزم الصادرة والواردة.
- `giant_api.py` — عميل Supabase المتزامن (دخول، إرسال، غرف، إدارة، وسائط).
- `runner.py` — التشغيل: تسجيل الدخول، ضبط البيئة، الانضمام للغرف، ثم حلقات المزامنة.

## التشغيل محليًا

```bash
pip install -r requirements.txt
export SUPABASE_URL="https://xxxx.supabase.co"
export SUPABASE_KEY="sb_publishable_..."   # أو SUPABASE_ANON_KEY
export GIANT_USERNAME="اسم_حساب_البوت"
export GIANT_PASSWORD="كلمة_المرور"
export OWNER_USERNAME="اسم_الماستر"
python -m talkin_full.runner
```

أو من ملف `config.json` الموجود في جذر المستودع بنفس الحقول (`supabase_url`, `supabase_key`, `username`, `password`, `owner_username`). متغيرات البيئة تسبق `config.json`.

للتشغيل من Docker أو Railway لا تحتاج تغيير شيء: `CMD` يشغّل `start.py`، والوضع الافتراضي `BOT_MODE=talkin`. لتشغيل بوت السفير القديم:

```bash
BOT_MODE=alsfer python start.py
```

## متغيرات البيئة الاختيارية

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `TALKIN_DATA_DIR` | `runtime_state/talkin` | مجلد الحالة الدائم (النقاط، الغرف، الهدايا المولدة، قوائم VIP). يجب أن يكون على Volume في Railway. |
| `TALKIN_ROOMS` | غرف البوت تلقائيًا | قائمة غرف مفصولة بفواصل ينضم إليها البوت عند التشغيل. |
| `TALKIN_VERIFICATION_ENABLED` | `false` | تفعيل بوابة التوثيق الأصلية في Talkin (VIP/موثق فقط). اتركها مغلقة ليستخدم الجميع الأوامر، أو فعّلها بعد توثيق الأعضاء. |
| `TALKIN_SYNC_VIP` | `true` | نسخ أسماء `vip_users.json` من مستودع aaa إلى قوائم VIP/التوثيق في Talkin عند كل تشغيل. |
| `PUBLIC_MEDIA_URL` | نطاق Railway أو `http://127.0.0.1:PORT` | عنوان خادم الأصول المحلي. لا يُرسل للتطبيق مباشرة؛ الملفات تُرفع إلى Storage. |
| `TALKIN_POLL_SECONDS` | `2` | فترة قراءة رسائل الغرف. |
| `PORT` | `8080` | منفذ خادم الأصول الداخلي. |

## الغرف والصلاحيات

عند التشغيل يقرأ البوت كل الغرف التي ينتمي إليها الحساب من `room_members` وينضم إليها. أضف البوت إلى أي غرفة من تطبيق جينات شات، أو استخدم `TALKIN_ROOMS`.

ليعمل الكيك والحظر وتغيير الرتب يجب أن تكون رتبة البوت في الغرفة **moderator** أو **admin** أو **owner**. إن كانت رتبته `member` سترفض دوال Giant الإجراء ويعرض البوت رسالة الفشل الأصلية.

الماستر (`OWNER_USERNAME`) يحصل على أوامر الإدارة كاملة، ويُضاف تلقائيًا إلى `masters.json`. أوامر التوثيق `vi@اسم` تعمل كالمعتاد وتكتب في `verified_users.json` داخل مجلد الحالة.

## الوسائط

صور الهدايا، بطاقات الألعاب، منشورات النشر، أغاني الموسيقى والملصقات تُولد محليًا كما في Talkin. قبل الإرسال يرفعها المحول إلى Supabase Storage:

- `bot-publish` للصور والمنشورات،
- `bot-music` للصوت،
- `bot-games` لصور الألعاب.

إن تعذر الرفع (صلاحيات أو Bucket غير موجود) يُرسل الرابط المحلي كما هو. تأكد من أن Buckets عامة للقراءة حتى تظهر الوسائط في التطبيق.

## ما الذي يعمل وما الذي لا يعمل

يعمل كامل منطق Talkin: الألعاب الفردية والجماعية (لودو، سلم وثعبان، الكريكيت، المزاد، الصياد، الكنز، الاستثمار، البنك، المزرعة، التعدين، الصيد، السوق، الزواج، المحكمة...)، قوائم المساعدة `help` و`a2`–`a6`، النقاط والتحويلات، الهدايا `gv` و`sa@`، الاستكشاف `ax@` والتفاعلات `lk/lv/dl/cm`، النشر `انشر@وصف` ثم إرسال صورة، الموسيقى `.sa`، الترحيب والحماية والفلتر، أوامر الإدارة، والرسائل الخاصة.

لا يعمل البث الصوتي المباشر (LiveKit) لأن جينات شات لا يوفره؛ يُرسل البوت تنبيهًا بدل ذلك. الهدايا الأصلية في بروتوكول Talkin غير مستخدمة أصلًا، وتبقى بطاقات الهدايا المصورة هي المعتمدة.

## الاختبارات

```bash
pip install pytest
python -m pytest talkin_full/tests -q
```

الاختبارات تحاكي Giant بالكامل (لا تحتاج شبكة) وتغطي: أوامر الغرفة، الرسائل الخاصة، الوسائط، الكيك/الحظر/الرتب، الانضمام والخروج، وقوائم الأعضاء.

## استكشاف الأخطاء

- **تعذر تسجيل الدخول**: تأكد أن `GIANT_USERNAME` يطابق اسم الحساب حرفيًا، وأن كلمة المرور صحيحة، وأن مشروع Supabase هو مشروع جينات شات الصحيح.
- **لا تظهر ردود**: راجع `logs/talkin_giant.log`. إن ظهر `رتبة البوت member` فالإجراء يحتاج ترقية رتبة البوت.
- **الوسائط لا تظهر**: أنشئ Buckets الثلاثة أو اجعلها عامة، أو اضبط أسماءها في `config.json`.
- **موسيقى لا تعمل**: ثبّت `ffmpeg` وتأكد من `yt-dlp` المحدّث.
- **إعادة تشغيل تفقد الغرف**: احفظ `TALKIN_DATA_DIR` على Volume.
