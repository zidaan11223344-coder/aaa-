# تعديلات الكتم والفلتر والرسائل الخاصة

## ملف التشغيل

شغّل الملف الموجود في جذر الحزمة: `bot.py`. لا تشغّل `games/bot.py` لأنه نسخة مختلفة داخل مجلد الألعاب وليست ملف التشغيل الرئيسي.

## أوامر الإدارة داخل الغرفة

| الأمر | النتيجة |
|---|---|
| `m@اسم_المستخدم 10` | كتم المستخدم لمدة 10 دقائق |
| `um@اسم_المستخدم` | إلغاء الكتم قبل انتهاء المدة |
| `mf@on` | تشغيل فلتر الكلمات للغرفة الحالية |
| `mf@off` | إيقاف فلتر الكلمات للغرفة الحالية |
| `+mf@كلمة` | إضافة كلمة محظورة وتفعيل الفلتر تلقائيًا |
| `mf@status` | عرض حالة الفلتر وعدد الكلمات |
| `b@اسم_المستخدم` | حظر فعلي عبر Giant |
| `ub@اسم_المستخدم` | فك حظر فعلي عبر Giant |
| `دعوة اسم_المستخدم` أو `دعوه اسم_المستخدم` | متاح لكل المستخدمين؛ يرسل دعوة خاصة باسم الداعي واسم الغرفة الحالية |
| `جماعية@الرسالة` أو `جماعيه@الرسالة` | للماستر فقط؛ يرسل الرسالة في الخاص إلى أعضاء الغرفة الحالية فقط، مع استثناء المرسل والبوت |
| `تشغيل اسم_الأغنية` | يشغّل من YouTube داخل الغرفة الحالية فقط، دون أكواد أو تفاعلات |
| `.تشغيل اسم_الأغنية` أو `.تشغيل رابط_Spotify` | يبحث في Spotify داخل الغرفة الحالية فقط، دون أكواد أو تفاعلات |

يجب أن يكون حساب من يكتب الأمر ماستر للبوت، وأن تكون رتبة حساب البوت داخل الغرفة مشرفًا أو أدمن عند استخدام الحظر والطرد والرتب.

> أمر `دعوة` لا يضيف العضو إلى الغرفة ولا يغيّر أي رتبة؛ هو إشعار خاص فقط، مثل: `أحمد يدعوك لغرفة نبض.`

> أمر `جماعية@` لا يرسل إلى جميع غرف المنصة؛ يرسل فقط إلى أعضاء الغرفة التي كُتب فيها الأمر. يوجد حد افتراضي قدره 500 مستلم للدفعة الواحدة ويمكن للمالك تغييره من `config.json` عبر `private_group_limit` إذا احتاج ذلك.

> Spotify لا يوفّر رابط صوت مباشر في هذه الحزمة. عند استخدام `.تشغيل` يستخرج البوت معلومات الأغنية من Spotify ثم يرسل ملفًا صوتيًا من نسخة عامة قابلة للتشغيل عند توفرها؛ وإن تعذر ذلك يرسل رابط Spotify في الغرفة نفسها.

## لعبة مليون التجريبية

بعد أن يفعّل المالك الاختبار في الخاص بالأمر `تشغيل اختبار@مليون`، يستطيع المستخدم كتابة `مليون`. المهلة **دقيقتان لكل مستخدم بين المحاولة والمحاولة**؛ عند المحاولة المبكرة يخبره البوت بالثواني المتبقية. الفوز وحده يعرض بطاقة الفائز وينشر النتيجة في الغرف، أما الخسارة فتظهر كنص في الغرفة الأصلية فقط.

> **ملاحظة مهمة:** الكتم يعمل على مستوى البوت؛ أي يتجاهل البوت رسائل وأوامر المستخدم المكتوم حتى تنتهي المدة. لا يمنع المستخدم من إرسال رسالة إلى Giant Chat نفسه، لأن واجهات Giant المتاحة في الحزمة لا تتضمن دالة كتم خادمية.

تُحفظ حالات الكتم في `mutes.json` بجانب `bot.py`، وتنتهي تلقائيًا عند مرور المدة.
