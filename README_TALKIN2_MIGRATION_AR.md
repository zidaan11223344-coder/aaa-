# دمج ميزات Talkin2 في Giant Chat

هذه الحزمة تضيف محركات الألعاب والأحداث ومتجر الأعضاء والعمليات المالية المهاجرة إلى بوت Giant Chat، مع بقاء تسجيل الدخول عبر Supabase كما هو. تشغيل البوت يحتاج Python والاعتماديات الواردة في `requirements.txt`، وملف إعداد خاص بالبيئة.

## إعداد التشغيل

1. انسخ `config.example.json` إلى `config.json` واملأ رابط Supabase ومفتاحه واسم مستخدم البوت وكلمة مروره. يمكن بدلًا من ذلك ضبط `SUPABASE_URL` وواحد من `SUPABASE_PUBLISHABLE_KEY` أو `SUPABASE_ANON_KEY` أو `SUPABASE_SECRET_KEY` أو `SUPABASE_KEY`، إضافة إلى `GIANT_USERNAME` و`GIANT_PASSWORD` و`OWNER_USERNAME`.
2. ثبّت الاعتماديات باستخدام `pip install -r requirements.txt`، ثم شغّل البوت بالطريقة المعتمدة في بيئتك (مثل `python bot.py`).
3. في Railway أو أي استضافة ذات قرص مؤقت، اربط تخزينًا دائمًا بمجلد المشروع أو بمسار الحالة الذي يستخدمه التطبيق؛ ملفات `runtime_state` تحفظ الألعاب والفعاليات والمتجر والاستثمارات.

## نقاط البوت

**نقاط البوت مستقلة عن نقاط أو رصيد Giant Chat.** التحويلات والجوائز والخصومات التي ينفذها هذا البوت تسجّل في `points.json` المحلي الخاص بالبوت، وتُعرّف الحسابات بواسطة UUID مستخدم Giant. لا يستدعي هذا الدمج دفتر عملة الشات.

لا تتضمن الحزمة `points.json` أو `config.json` أو ملفات الغرف والرتب والحظر؛ فهي بيانات خاصة ببيئة التشغيل. عند تحديث تثبيت قائم، احتفظ بنسخة احتياطية من `points.json` وملفات الإدارة والغرف والإعدادات، ولا تستبدلها بنسخة فارغة. أبقِ ملفات الحالة الدائمة متاحة بعد إعادة التشغيل.

## أوامر مضافة/مربوطة

- تحويل نقاط البوت: `sb@اسم_المستخدم@المبلغ`. يتطلب VIP موثقًا ويُنفّذ كتغيير ذري بين UUID المرسل والمستلم. يستخدم معرّف رسالة Supabase لمنع تكرار الخصم عند إعادة تسليم الرسالة نفسها.
- المتجر: `متجر` أو `shop`، ثم `sby 1` إلى `sby 6` أو `شراء 1` إلى `شراء 6`. الشراء يخصم نقاط البوت ويحفظ الاستحقاق محليًا؛ شراء عناصر الغرفة يتطلب إرسال الأمر من الغرفة.
- البورصة: `بورصة` ثم اختيار 1–4 (ذهب، فضة، نفط، أرض) ثم مبلغ الاستثمار. تُخصم نقاط البوت وتُحفظ العملية، وتُسوّى بعد دقيقة. تُحفظ نوايا فتح الاستثمار لاستعادتها بعد توقف مفاجئ.
- الرهانات الثنائية: `رهان@المبلغ`، `مراهنة@المبلغ`، `مضاربة@المبلغ`، `استثمار@المبلغ` أو `حظي@المبلغ`. يحجز البوت مبلغ الطرف الأول، وينضم منافس خلال دقيقتين، ثم تسوى الجولة مرة واحدة ويعاد المبلغ للفائز مع ربح قدره مبلغ الرهان.
- أضيفت كذلك ألعاب اللوح والإحصاءات والأحداث والمزاد والكريكيت والألماسة النادرة بحسب الملفات المهاجرة في المشروع.

منتجات الحماية والإخفاء في المتجر تُسجل كاستحقاقات مؤقتة أو دائمة في حالة البوت. تفعيلها في السلوك يتطلب وجود الحدث أو الميزة المناظرة في Giant Chat؛ لا يدّعي الدمج إنشاء وظائف حماية أصلية داخل تطبيق Giant لم تكن موجودة فيه.

## الاختبارات

اجتازت مجموعة الاختبارات كاملة: 128 اختبارًا ناجحًا. عُدّل اختبار رندر الهدايا ليستخدم قالب الحزمة كخلفية بديلة عندما لا تتوفر صورة الاختبار الخارجية في `/mnt/data/`.
