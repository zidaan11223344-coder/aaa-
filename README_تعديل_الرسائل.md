# تعديل رسائل البوت يدويًا

افتح `messages.json` وعدّل النصوص فقط بين علامتي الاقتباس. لا تغيّر أسماء المفاتيح ولا تحذف الأقواس أو الفواصل، لأن البوت يقرأ الملف عند إرسال كل رسالة.

## أهم الأقسام

| القسم | ما يمكن تعديله |
|---|---|
| `music` | بطاقة الأغنية ورسائل بدء التشغيل وروابط الأغاني |
| `publish` | بطاقة الصورة، طلب إرسال صورة، وتحذير الملف غير الصوري |
| `social.labels` | أسماء الإعجاب والحب وعدم الإعجاب والتعليق والبلاغ |
| `social.notifications` | رسائل الخاص عند الإعجاب أو التعليق أو البلاغ على أغنية أو صورة |
| `sharing` | رسائل مشاركة الأغنية إلى الخاص والنتيجة |
| `private_messaging` | نص رسالة الماستر الجماعية في الخاص، وحد الإرسال ورسائل النتيجة |
| `invitations` | نص دعوة الغرفة الخاصة ورسائل الخطأ والنجاح |
| `presence` | رسائل حالة المستخدم والغرف |
| `games.million_*` | البحث والفوز والخسارة ورسالة مهلة المحاولة التالية للعبة مليون |
| `moderation` | رسائل الحظر والطرد وفلتر الكلمات |
| `help_pages` | صفحات المساعدة التي يراها المستخدمون في الغرف |

المتغيرات بين الأقواس مثل `{title}` و`{actor}` و`{room}` يملؤها البوت تلقائيًا. احتفظ بها كما هي أو انقلها داخل النص؛ لا تغير اسمها.
