# النسخ الاحتياطي الكامل إلى Telegram

## متغيرات Railway

استخدم المتغيرين التاليين:

`TELEGRAM_BOT_TOKEN`

`TELEGRAM_BACKUP_CHAT_ID`

ضع في `TELEGRAM_BACKUP_CHAT_ID` رقم تعريف مجموعة Telegram التي تريد استقبال النسخ فيها. لا تضع التوكن داخل هذا المتغير.

## ماذا تحفظ النسخة؟

النسخة تشمل ملفات المشروع والبرامج والأصول وملفات JSON وبيانات الماسترات والنقاط والألعاب والأوامر والإعدادات وملفات الحالة الموجودة داخل مجلد المشروع.

لا يتم وضع الأسرار وملفات `.env` ومفاتيح الحسابات وملفات service-account وملفات Cookies الخاصة بـ YouTube/Spotify أو ملفات Python المؤقتة داخل النسخة.

## أمر الماستر

من خاص البوت:

`نسخ احتياطي`

سيظهر أولًا:

`⏳ جاري تلبية طلبك... انتظرني، سأرسل لك النتيجة بعد التنفيذ.`

ثم يرسل ملف النسخة إلى مجموعة النسخ. إذا كان الملف أكبر من الحد الآمن للإرسال، يقسمه البوت إلى أجزاء مرقمة.

## إعداد المجموعة

1. أنشئ مجموعة خاصة للنسخ.
2. أضف البوت إليها.
3. اجعل البوت قادرًا على إرسال الملفات في المجموعة.
4. ضع Chat ID للمجموعة في `TELEGRAM_BACKUP_CHAT_ID`.
5. أعد تشغيل Railway.
6. نفذ `نسخ احتياطي` من خاص البوت بحساب الماستر.
